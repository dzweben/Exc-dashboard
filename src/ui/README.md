# EXC site: design brief

Read-only progress page. Danny logs by talking to Claude; he opens this to see
what hasn't been hit, his bests and trends, and consistency. **Keep it small**:
no logging UI, no settings, no extra panels unless he asks.

Look: its own identity (not the EF Console's punk zine). Dark instrument panel,
rounded cards, Space Grotesk + JetBrains Mono, a cyan→violet→pink accent
gradient, each exercise colored by its area (type color). Phone-first: one
column under 860px, no horizontal scroll.

Files: `main.js` (fetch + render), `dom.js` (h/s/mount), `styles/app.css`,
`template.html`.
